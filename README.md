# GRNN Bio-Manifold v11: local learning in networks of data-fitted neurons

Recurrent networks are built entirely from differentiable single-neuron models fitted to
Allen Cell Types patch-clamp recordings (GFR bank, AllenInstitute/GRNN, commit `835a535`).
Each cell's intrinsic parameters are frozen; only the synaptic weights learn. The project
compares:

- exact BPTT;
- a cell-local, forward-in-time rule (e-prop with random feedback), with and without the
  cell's own spike-history term β in its eligibility trace;
- a frozen recurrent reservoir.

These are compared on three working-memory tasks. It also tests whether cell identity,
heterogeneity, wiring and operating point matter.

**Status:** the confirmatory protocol was locked (`docs/PREREGISTRATION_v11.md`,
`docs/LOCK_v11.json`) before the held-out donor cohort was used. Results and the preprint
draft are in `results/v11/confirmation/` and `paper/`.

## Layout

| path | content |
|---|---|
| `grnn_bio/` | model, circuit, tasks, learners, analysis (NumPy) |
| `tests/` | 127 unit/integration tests (`python -m pytest tests`) |
| `configs/v11/` | every configuration, generated by `scripts/v11_configs.py` |
| `docs/WORKLOG_v11.md` | what was audited and changed from v7, and why |
| `docs/PREREGISTRATION_v11.md`, `docs/LOCK_v11.json` | locked protocol and its hashes |
| `results/v11/dev/` | D0 budget pilot (development cohort) |
| `results/v11/tune/`, `tune2/` | validation-only learning-rate search, `final_selection.json` |
| `results/v11/rehearsal/` | full-design rehearsal on the development cohort |
| `results/v11/confirmation/` | confirmatory runs (held-out cohort): suite tables and `analysis/` |
| `scripts/analysis/` | confirmatory tests, per-neuron alignment |
| `scripts/figures/` | every paper figure |
| `paper/` | LaTeX source and `main.pdf` |

Per-run raw outputs (learning curves, per-trial predictions, population analyses) are
attached to the GitHub release as compressed archives. Model checkpoints are not uploaded;
every run is deterministic given its seed and can be regenerated.

## Reproduce

```bash
python -m pytest tests
python scripts/v11_configs.py confirmation
python scripts/lock_protocol.py verify
python scripts/run_many.py --jobs 26 --out results/v11/confirmation configs/v11/confirmation/*.json
python scripts/analysis/confirmatory_tests.py --root results/v11/confirmation --prefix c --out results/v11/confirmation/analysis
```
